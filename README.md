## Projects

### DriveWise – Automotive Brochure Question-Answering System

DriveWise is a domain-specific Question-Answering system designed to answer user queries from automotive PDF brochures. It processes car brochures as the knowledge source and provides natural-language answers about vehicle features and specifications.
